Connect your online counter

Paste the two values from your Supabase project's Project Settings → API page, then click Save. They are free and public.

Where do I find these?
  1. Go to your project on supabase.com
  2. Click Project Settings (gear icon) in the sidebar
  3. Click API
  4. Copy the Project URL into the first box
  5. Copy the anon public key into the second box
